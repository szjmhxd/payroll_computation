# 摸鱼薪资计算器开发计划

## 项目概述
开发一个实时工资计算网页应用，让打工人能够实时看到自己今天赚了多少钱，增加工作动力（或摸鱼动力）。

## 功能需求（本期实现）

### 核心功能
1. **薪资设置**
   - 税后月薪（元）
   - 上班时间
   - 下班时间
   - 午休开始时间
   - 午休结束时间
   - 午休时长（分钟）— 根据开始和结束时间自动计算，也可手动输入
   - 午休时间是否计入薪资（开关）
   - 是否双休（开关）
   - 发薪日（每月几号）

2. **实时薪资计算**
   - 今日已赚金额（实时更新）
   - 今日进度条（百分比）
   - 距离下班倒计时
   - 本月已赚金额
   - 实时时薪
   - 每秒进账金额

3. **发薪日倒计时**
   - 距离发薪日还有多少天

4. **跳过规则**
   - 计算薪资时可选跳过节假日（复选框）
   - 计算薪资时可选跳过周末（复选框）

### 暂不实现（后续版本）
- 网络日历节假日导入
- 税前薪资计算
- 社保/医保/公积金计算
- 本月工作日倒数
- 赚钱速度换算（奶茶、咖啡等）

## 技术方案

### 技术栈
- **前端**：HTML5 + CSS3 + JavaScript（纯原生，无框架依赖）
- **时间选择器**：Flatpickr（轻量级、无依赖、支持中文、丰富主题）
- **样式**：使用CSS变量实现主题色，参考截图中的绿色主题
- **存储**：localStorage 保存用户设置

## 数据结构

### 用户设置 (localStorage)
```javascript
{
  "monthlySalary": 15000,        // 税后月薪
  "workStartTime": "09:00",      // 上班时间
  "workEndTime": "18:00",        // 下班时间
  "lunchStartTime": "12:00",     // 午休开始时间
  "lunchEndTime": "13:00",       // 午休结束时间
  "lunchDuration": 60,           // 午休时长（分钟）— 自动计算或手动输入
  "lunchIncluded": true,         // 午休是否计入薪资
  "isDoubleRest": true,          // 是否双休
  "payDay": 15,                  // 发薪日（每月几号）
  "skipHoliday": true,           // 跳过节假日
  "skipWeekend": true            // 跳过周末
}
```

### 计算公式
```
月工作日 = 双休 ? 21.75 : 25.75（或根据实际日历计算）
日工作时长 = (下班时间 - 上班时间) - (午休计入薪资 ? 0 : 午休时长)
每秒薪资 = 月工作日薪资 / 日工作时长 / 3600
今日已赚 = 从上班时间到现在的秒数 × 每秒薪资
```

## 验证方式

1. **功能验证**
   - 设置不同薪资，检查计算是否正确
   - 设置不同上下班时间，检查进度条和倒计时
   - 测试午休计入/不计入薪资的差异
   - 测试双休/单休的工作日计算
   - 测试午休时间联动：修改开始/结束时间，时长自动更新；修改时长，结束时间自动更新

2. **数据验证**
   - 刷新页面后设置是否保留
   - 关闭浏览器后重新打开设置是否还在

3. **显示验证**
   - 响应式布局在手机和电脑上显示正常
   - 金额显示格式正确（保留2位小数）
   - 倒计时显示正确
