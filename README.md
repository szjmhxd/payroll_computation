# 摸鱼薪资计算器

实时工资计算网页应用，让打工人能够实时看到自己今天赚了多少钱。

## 功能特点

- **实时薪资计算**：根据设置的月薪和工作时间，实时计算今日已赚金额
- **今日进度条**：显示当天工作完成百分比
- **下班倒计时**：距离下班还有多长时间
- **统计卡片**：本月已赚、实时时薪、每秒进账、距离发薪日
- **薪资设置**：税后月薪、上下班时间、午休时间、是否双休等
- **午休时间联动**：开始时间、结束时间、时长三字段自动联动计算
- **跳过规则**：可选跳过周末、跳过节假日
- **发薪日倒计时**：距离发薪日还有多少天
- **数据持久化**：设置自动保存到 localStorage，刷新页面不丢失

## 技术栈

- HTML5 + CSS3 + JavaScript（纯原生，无框架依赖）
- Flatpickr 时间选择器（轻量级、支持中文）

## 使用方法

1. 直接打开 `index.html` 即可使用
2. 在设置区域配置您的薪资信息
3. 点击"保存设置"保存配置
4. 页面会自动实时计算并显示薪资信息

## 设置说明

| 设置项 | 说明 |
|--------|------|
| 税后月薪 | 您每月实际到手的工资 |
| 上班时间 | 每天上班时间 |
| 下班时间 | 每天下班时间 |
| 午休开始 | 午休开始时间 |
| 午休结束 | 午休结束时间（自动计算） |
| 午休时长 | 午休时长分钟数（自动计算） |
| 午休计入薪资 | 午休时间是否算作工作时间 |
| 双休 | 是否周末双休 |
| 跳过周末 | 计算薪资时是否跳过周末 |
| 跳过节假日 | 计算薪资时是否跳过节假日（需网络日历） |
| 发薪日 | 每月几号发薪 |
